这两件事同一天发生，搁以前我大概会兴奋地转发，现在第一反应是：这会影响我哪个 SKU 的供货成本，或者会不会给我带来新的客服压力？

## 定价分裂这件事，我其实有点看不懂

[Google AI 官宣](https://x.com/GoogleAI/status/2087949042961514983) Gemini 3.7 Flash 上线，比上一代便宜 50%，主打编程和 Agent 任务，声称是目前最强的日常工作模型。同一天，DeepSeek V4-Pro 发布，峰值定价比以前高出好几倍，有人整理的[价格对比图](https://x.com/op7418/status/2087865228122108037)显示缓存命中峰值涨了将近 12 倍。

一个往下打，一个往上走，这两家是不是开会商量过要演对手戏？

我自己对这套"峰谷定价"逻辑其实没太搞懂。字面意思懂，但具体对我的业务影响是什么，说实话我没算清楚。我现在卖的 Claude 中转和 Codex 中转，背后走的是什么调用逻辑、有没有受这两家定价变动的传导，我得去问供应商才知道。

这大概是做账号生意的局限——我站在零售端，上游发生了什么，经常是滞后知道的。

## 降价对我是好事还是坏事，答案很微妙

直觉上，Gemini 降价，用的人多，我那边 Gemini 年卡的询盘会不会多一些？有可能。但这条逻辑成不成立，取决于用户到底是因为贵才没用，还是根本就没听说过。

我长期观察下来，我的用户里真正会主动关注 API 定价的，其实是少数。更多人问的是"哪个好用"、"哪个最便宜的入门款"、"Cursor 怎么配置"。他们不关心每百万 token 多少钱，他们关心的是这个月我花多少钱能用上。

所以 Gemini 降 API 价，对我的直接影响可能比想象中小。真正影响到我 SKU 定价的，是上游供应商的批发价，而不是 Google 官方标出来的开发者价格。

DeepSeek 涨价就更奇怪了。之前 DeepSeek 一直是那个"又便宜又能打"的形象，这次涨成这样，是真的供不应求，还是在学 Claude 筛客户？我不知道。但我能预感到的是——如果 DeepSeek API 中转这个品类有在卖的同行，接下来定价得重新算了。

## 我店里真正被这类消息折腾到的，是教程和客服

不管是 Gemini 出新版还是 DeepSeek 涨价，我这边最先感受到的不是销售额变化，而是用户开始问问题了。

"我买的三合一还能用吗"、"Gemini 出了新版本你们有没有更新"、"DeepSeek 的中转是峰值价格还是空闲价格"——这类问题会在消息出来的当天密集涌进来。

这是我做这个生意最耗时间的部分：不是备货，不是上新，是解释。每次大模型有点动静，用户的理解成本就上来了，而理解成本最终转化成我的客服成本。

我想做 AI 客服来扛这部分压力已经想了很久，但一直没找到足够稳的方案。不是技术上做不到，是售后场景太复杂，有时候问题本身是模糊的，用户说不清自己遇到什么问题，AI 客服更说不清。

现在能做的还是靠教程和 FAQ 去提前拦截——发一篇新的说明文档，解释清楚 Gemini 3.7 Flash 和我现在卖的产品是什么关系，能用还是不能用，有没有影响。先把问题消化在用户动嘴之前。

## 最后随便说一句

每隔一段时间，AI 这个圈子就会出现一次"定价重新排列"的节奏。上一次让我印象深的是 GPT-4 降价那回，当时供应商那边的价格也调整了，我忙了好几天重新算利润率。

这次 Gemini 降、DeepSeek 涨，会不会触发类似的连锁反应，我现在判断不了。只能先盯着供应商那边有没有动静，同时把相关产品的教程更新一遍，等着看后面几天的数据说话。

还是那句话：卖铲子的人，矿场涨跌不是我能控制的，我能控制的是铲子有没有备货、教程有没有写清楚、用户问了有没有人答。先把这几件事做稳，其他的随它去。
