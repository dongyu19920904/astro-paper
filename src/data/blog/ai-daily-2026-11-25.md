搜同一个词，Google 给你的是整理过的文章，Reddit 的帖子淹在里面，X 上的反应更是几乎找不到。这不是算法偏心，是这几个平台本来就互相隔开，没有哪个搜索引擎同时接进去。

last30days-skill 想解决的就是这件事。它不是一个新的搜索引擎，而是一个 AI 智能体技能，意思是你在 Claude Code 或 Cursor 这类 AI 编程工具里装上它，给它一个研究主题，它会同时去 Reddit、X、YouTube、HN（一个技术讨论社区）和 Polymarket（一个用真实资金押注的预测市场）这几个地方检索，再把结果综合成一份摘要。

各个平台各自都有 API，也就是开放给外部程序读取数据的接口，但拿到所有权限比较麻烦。这个工具的思路是让用户自己带凭据，Reddit 和 HN 不需要额外配置，直接能用；X、YouTube 需要登录或提供 API Key，也就是平台颁发的一串身份令牌，才能解锁。几个地方同时查，比你自己挨个打开窗口快很多。

我在意的是它打分的方式。这份摘要不是按编辑判断来排序，而是按真实参与度：Reddit 的点赞数、X 的互动量、Polymarket 的投注金额。Polymarket 这个来源有点特别，押注是用真实钱的，押错要亏，所以这里的"大家觉得怎样"比纯粹的情绪帖更难造假。这并不是说结果一定准确，只是这种排序逻辑和你平时读到的编辑精选文章来路不同。两者都有偏，但偏的方向不一样。

## 适合用在什么地方

README 里作者举了几个场景：明天要见某人，先查他近 30 天的推文和 YouTube 访谈；去迪士尼前查社区对某个游乐项目的最新反馈；做一个项目前，先看看大家在哪里卡住。这些都是"近期这件事在真实人群里是什么状态"的问题。

它不擅长给你一个定论，它给的是当前讨论分布。如果你想知道某个工具有没有用，它能告诉你 Reddit 上最高赞的批评是什么、X 上谁在推荐、YouTube 上有没有实测视频，但不会替你决定要不要试。对于真实讨论分散在各处的话题，这比单靠一个来源要全一些。

有几件事值得注意。摘要的质量依赖你设置的推理提供者，就是你选择用哪个 AI 模型来重新排序和整合结果；如果不配置，它会退到本地一个轻量打分模型。搜索调用的是各平台的 API，实际取回的内容受限于每个平台当时开放的范围，不代表该话题的全部讨论。README 读取是截断版，一些细节未能完整读到，这里只用读到的部分。

这个工具代码按 MIT 协议开源，默认不向外部传数据，只有你配置了外部推理提供者时，它才会将检索到的片段发出去做重新排序。
