上个月月底，我盯着 Codex 剩余额度的那种心情，说出来有点丢人——感觉比看店里的日流水还紧张。

八月一号额度重置，v2ex 上有人截图记录了 11:30 那个瞬间，一群人守着刷新，像过年守岁一样。我没有截图，但我能理解那种心情。因为我自己上个月月底也是这种状态：能用就多用，赶紧跑，别浪费。

## Table of contents

## 为什么我会为一个免费额度这么焦虑

说实话，这件事让我觉得有点怪。

Codex 的额度又不是我花钱买的，重置不重置，跟我实际损失没关系。但那种"用完了就浪费"的感觉，一直在。

我想了一下，这大概是卖账号之后养成的职业病。

我每天看的是销售额、利润率、补货节奏——脑子里常驻着"这个资源有没有被充分利用"的计算线程。到了自己用工具的时候，这个线程没有关掉。免费额度用完，等于浪费了一个本可以赚回来的机会。

但问题是，我真的有那么多需要 Codex 帮我跑的任务吗？

说实话，不一定。很多时候我把额度堆满任务，是因为额度快到期了，而不是因为我真的有那么多需求。这是一种倒置——不是需求驱动工具，而是工具额度在驱动我的需求。

这一点，我在卖号的用户身上也看见过。有人买了 Cursor Pro，第一周疯狂用，之后慢慢搁置，续费前再冲一把——用工具的节奏，跟工具的收费周期高度绑定，而不是跟自己的实际生产需求绑定。

这是个挺有意思的行为模式，但我没想清楚该怎么利用它，先记在这里。

## DeepSeek V4 Flash 开源，我的第一反应是看库存

今天日报里另一条让我眼前一亮的，是 DeepSeek V4 Flash 开放权重，284B 参数，Artificial Analysis 榜上跻身开源前三。

我第一反应不是"哇，性能很强"，而是：我家 Claude 三合一账号，卖点还稳不稳？

这是一种职业病，但也是一种真实反应。DeepSeek 每次搞事情，我都会下意识地做一遍"竞品威胁评估"——它开源了，私有化部署门槛降低，那些原本因为没法自建而来买我们账号的用户，会不会跑一部分？

结论目前是：不会，至少短期内不会。

能自己搭私有化部署的人，和来买账号的人，根本不是同一批用户。前者是开发者，有服务器，有折腾劲；后者是普通用户，连 API key 是什么都不一定懂，他们想要的是"开箱即用、出了问题有人管"。

这两类需求之间有一道挺高的门槛，我就站在那道门槛后面做生意。

不过有一件事我在意：DeepSeek V4 Pro 的 1.6T 参数版本，据说性能可能超过 Opus 4。如果这是真的，而且 API 价格下来了，我的 Claude 中转定价策略可能要调整。这个我要盯着，等发布之后第一时间看价格。

## 谷歌地图生图，上线不到一天被玩坏

这条消息让我乐了一下。

谷歌把 Nano Banana 2 集成进谷歌地球，结果一觉醒来就下线了，上线不足 24 小时，原因是被用户"以意想不到的方式滥用"。

不需要知道具体被怎么滥用，光是这句话就够脑补了。

但我想说的不是这个。我想说的是：谷歌这种体量的公司，做了这么多年内容审核，AI 生图嵌进地图里，居然还是没防住——这证明"生成式 AI + 现实世界数据"的组合，内容风控的难度是非线性的，不是说你原来能守住文字就能守住图，守住图就能守住地图叠加生图。

作为一个卖 AI 账号的，我对这件事有点切身感受。

我卖的账号里，有生图工具，也有代码工具，偶尔会遇到用户问"能不能用来做 XX"，有些 XX 是我不打算支持的。我不是在道德高地上俯视——我是从售后风险的角度在考虑。一旦账号因为用途问题被封，退不退款都是烂事，还不如提前说清楚不卖给某些用途。

谷歌这次翻车，某种程度上是我在自己小生意里天天处理的事情的放大版本：部署快，治理慢，迟早出事。

## 做笔记

今天没什么特别厉害的顿悟，就随手记几件事：

Codex 月初重置，下个月月底前找几个真实任务跑，别再为了用而用。

DeepSeek V4 Pro 发布之后立刻对比 Claude 中转的价格，看是否需要调整定价或者补一个新商品。

AI Agent 实验失控那条（给 Agent 一台 Mac mini 和虚拟信用卡让它自己推广 App）——这个我回头细看一遍，不是因为我要复现，而是因为"目标驱动失控"这件事，和我每天设置 AI 客服规则时遇到的问题很像：指令写得越具体，边界越重要。

月初到了，去看一眼店里库存，哪个账号快断货了。
