"每天 18 点自动跑，推到手机上，零成本。"一个工具将这几点凑齐了，对想搭自己投资参考的人，挺难不心动。我最先想确认的不是它能分析几个市场，而是"零成本"后面那行小字到底说了什么。

这个项目叫 daily_stock_analysis，用大模型分析 A股、港股、美股等市场，放在 GitHub Actions 上定时跑，不用自己租服务器。GitHub 的免费运行额度加上项目默认的免费行情数据源，确实让你不花一分钱就能启动。

免费是它的入口，也是我最在意的风险点。项目 README 写了一句容易被扫过去的话：免费数据源受上游限流、接口变动和网络波动影响，稳定性不保证。换成日常说法，免费数据是从别人的接口里拿的，别人限制你的请求频率、改了接口格式、或者网络波动，你的分析就可能拿不全数据。工具本身没出问题，是它依赖的免费通道断了或缺了。

问题在于，这种缺不会提醒你。假设某天 18 点的推送照常到了，但因为免费源被限流，某只股票的行情只拿到了一半。大模型还是会照常生成一份报告，该有结论有结论、该有买卖点位有买卖点位，你从推送上很难看出今天的依据其实缺了一块。免费不影响今天能不能跑，影响的是跑出来的东西可不可信。

出路项目也给好了：长期定时或批量使用时，建议换成 token 型数据源。token 就是一串类似密码的字符，注册后从数据源平台拿到，填进项目的配置里。A股可以用 Tushare，港股和美股可以用 Longbridge。有些是免费的，有些需要付费，但比免费源更稳定，也能补上免费源拿不到的字段。

检查的办法不复杂。部署完先手动跑一次，翻日志里有没有数据获取失败或字段为空的提示。之后连续看几天推送，留意同一些字段是不是经常缺失。如果你只是随便翻翻，免费源可能够用；如果每天想据此做判断，那一步 token 的钱大概省不掉。

项目自己在最后写了一条免责声明：仅供学习和研究使用，不构成任何投资建议。工具能每天自动跑，不等于跑出来的分析能直接用来下单。
