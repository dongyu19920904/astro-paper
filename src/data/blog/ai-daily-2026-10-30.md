如果你订了 ChatGPT Pro，最近可以去设置里检查一下账单页面，有一笔等额的 API 额度可以领取。Pro 档每月 $200 订阅，对应 $200 的 API 额度。领取入口在网页版 ChatGPT 的「设置 - 账单」页面，部分用户暂时看不到按钮，刷新几次再确认。

但领到之后呢？这是我更在意的问题。额度到手不等于知道怎么用，对第一次接触 API 的人来说，"多了一笔余额"和"真的能做成一件事"之间，还差一些说明。

## API 额度和普通 ChatGPT 聊天的区别

在网页版 ChatGPT 里对话，用的是订阅资格，不消耗 API 额度。API（直译是"应用程序接口"，可以理解成让其他软件直接呼叫 GPT 模型的通道）额度是给另一类使用场景准备的：你不是在 ChatGPT 网页里打字，而是通过别的工具、脚本或平台调用 GPT，费用从这笔余额里扣。

举一个假设的例子。有人想用 Cursor（一款内嵌了 AI 的代码编辑器）写一段自动整理文件夹的脚本，但不想每次都切回 ChatGPT 窗口复制粘贴。配置好 API Key（相当于一把钥匙，让 Cursor 知道用你的账号计费）之后，Cursor 里的对话就直接消耗 API 额度。这笔赠送的余额就能派上用场。

类似的场景还有：在 Notion AI 之外接一个自定义的摘要工具、用 Make 或 Zapier 这类自动化平台串联几个步骤、在 Python 脚本里加一段生成文字的逻辑。这些都需要 API Key 和余额，而不是订阅账号。

值得注意的是，这笔额度能用多久，取决于你实际调用的频率和选择的模型版本。调用 GPT-4o 比调用轻量版本消耗快得多，$200 在高强度使用下可能比预期花得快。来源材料里没有关于有效期的说明，建议领取后在账单页面留意剩余余额。

## 怎样确认领到了、有没有在用

领取之后可以在 OpenAI 的 Platform 页面（platform.openai.com）登录同一个账号，账单部分会显示余额。如果你在某个工具里配置了 API Key 并发起了请求，这里的使用记录会更新。没有调用记录，余额不会动。

这是最直接的检查方式：看余额有没有减少，对应的时间段有没有调用记录。如果配置完工具后余额纹丝不动，多半是 Key 没填对或者工具还没真的走 API 通道。

我在意这件事，是因为"订阅送额度"这个消息本身容易让人觉得有了什么新能力，但如果不清楚 API 和普通聊天的区别，领完就放在那里也不奇怪。能不能用上，取决于你现在是否有一个需要 API 才能打通的使用场景。如果日常只在 ChatGPT 网页里聊天，这笔额度暂时用不到；如果你正好想把某个工具接起来，它是一个不用另外充值的起点。
