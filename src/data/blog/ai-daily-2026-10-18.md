Every 联合创始人 Dan Shipper 历时数月完成了 Codex 翻盘的深度还原，采访了六位核心参与者。报道本身的信息量不是重点，重点是他用的发布形式：六场完整采访文字稿随文附上，每句引语都能跳回原始对话。他管这叫"智能体原生"。

传统深度报道的问题是引语无法核验。记者从数小时采访中提炼几句话，读者只能相信记者的判断。即使原始录音公开，人工比对的成本也高到不现实。Dan 的做法是将六场采访的完整文字稿作为报道附件，正文每句引语都标注了出处，点击后直接跳转到对应采访的上下文段落。

这种形式真正的使用场景不是人工阅读六份文字稿，而是交给 Agent 交叉比对。假设你对报道中某个关键转折有疑问，例如 Tibo 接手团队的具体时间点，可以让 Agent 从六份文字稿中提取所有相关描述，检查是否存在矛盾或被选择性引用的情况。又或者你想知道某个决策是谁提出的，Agent 可以找出所有提到这个决策的段落，展示不同参与者的版本差异。

我的判断是，这种形式将深度报道的核验成本从"不可能"降到了"可执行"。适用边界很明确：你需要配合 Agent 使用，需要有具体的核验问题，并且愿意为这个问题投入几分钟让 Agent 跑完比对。它不能替代记者的采访和提炼工作，也不会让每篇报道都值得核验。但对于涉及关键决策、时间线或多方叙事冲突的报道，这是第一个让读者能实际动手核验的方法。

目前的限制是文字稿质量依赖转录准确度，Agent 的比对能力受限于模型的长文本理解和多文档推理能力。如果你想试用这个方法，建议从明确的事实性问题开始，例如时间、人物、具体数字，而不是观点或情绪表达。核验结果仍需要人工最终判断，Agent 只是将不可能的人工比对变成了可能的初步筛查。
