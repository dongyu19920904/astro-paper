千问音视频调用成本降价超九成，Anthropic 开源终端编码工具登上热榜。技术扩散越来越快，工具也越来越便宜，但我这个卖账号的人最近一直在想一个问题：降价能让我省钱，但客服和售后的时间成本什么时候能降下来？

## 千问降价让我重新算了一次成本

看到千问音视频处理降价 93%，第一反应不是"真便宜"，而是"我能不能用它来做点什么"。

爱窝啦现在每天销售额大约 3000 块，利润大约 1000 块，听起来还行。但真正消耗我时间的不是卖号本身——卡密自动发货、24h 自助，这些早就搞定了。真正吃时间的是客服、教程解释、售后边界判断，还有用户说"我不会用"时要怎么回。

之前也想过用 AI 客服，但总觉得不够稳定。现在多模态成本降下来了，理论上可以让 AI 直接看截图、听语音、看视频教程，然后自动回答。问题是，这事儿到底能不能做到不用我盯着？

我不想再花一堆时间去调试一个"看起来很厉害"但实际还得人工兜底的系统。

## Claude Code 让我想起重复操作的时间黑洞

Anthropic 开源了终端 AI 编码工具 Claude Code，一天新增 444 Stars。说白了，就是让 AI 直接在终端里理解项目、执行任务、处理 git 工作流程。

我不是程序员，但我现在也经常要改代码——发卡站的页面、日报项目的模板、教程文档的格式。每次都要打开文件、找到那一行、改完提交、再测试一遍。这些操作本身不难，但累加起来就是时间黑洞。

如果 Claude Code 真的能让我直接说"把这个按钮改成绿色"，然后它自己去找文件、改代码、提交 git，那确实省了很多事。但问题是，我需要先确认它不会乱改其他东西，也不会把我的项目历史上传到哪里去。

对，我说的就是 ZCode 那件事——用户发现它在静默上传完整的 Git 历史。这事儿让我有点警惕。AI 工具越强大，我就越需要确认它的边界在哪里。

## 朱啸虎说技术扩散超过技术进步，我深有体会

朱啸虎在演讲里说，开源模型五年会走完 Linux 三十年的路。技术扩散速度超过技术进步速度之后，AI 创业的决胜要素只剩人文和商业。

这话我特别有感触。

一年前，卖 AI 账号还是个"技术门槛"的生意——你得知道怎么搞到稳定的供应链、怎么配置自动发货、怎么写教程让用户看懂。现在呢？技术门槛越来越低，工具越来越多，竞争对手也越来越多。

我现在真正的护城河不是"我有账号"，而是"用户愿意来我这买"。这就回到了商业本质：你的服务体验好不好、你的教程清不清楚、你的售后响不响应、你的价格划不划算。

但问题是，这些事情都需要时间。尤其是客服和售后，几乎每天都有人问"为什么登不上"、"这个账号能用多久"、"我不会操作怎么办"。我一个人能应付，但如果想再往上走，这套系统必须得能自动化、能复制、能规模化。

所以我最近一直在想：AI 能不能帮我把这些重复劳动系统化？不是说完全不用我管，而是能不能让 AI 先处理 80% 的常见问题，我只需要处理那 20% 真正需要人判断的情况？

## 真正的问题是：我怎么把时间腾出来

千问降价、Claude Code 开源、朱啸虎的判断，这些新闻看起来都很有道理。但对我来说，真正的问题不是"技术够不够好"，而是"我怎么把这些技术用起来，让自己从客服和杂事里腾出时间"。

我有三条主线：AI 一人公司、AI 生命延续学、维持好 AI 账号生意。但现在第三条占了我太多时间，导致前两条一直推不动。

所以我接下来要做的事情很明确：
- 先把常见问题梳理出来，做成 FAQ 和自动回复模板
- 试试用多模态 AI（比如千问新版本）来处理截图和语音问题
- 测试 Claude Code 能不能让我更快地调整页面和教程
- 确认这些工具的数据安全和隐私边界

技术扩散越快，竞争就越激烈。我不想靠技术优势活着，但我需要用技术让自己活得更省力。
