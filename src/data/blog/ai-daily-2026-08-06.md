刚看到 DeepSeek 涨价的消息，脑子里第一个念头不是"API 成本怎么算"，而是想起 2025 年初我在闲鱼搬运 DeepSeek API 赚差价那段经历。那是我第一次卖账号，赚了几十块。现在回头看，那几十块的意义远大于金额本身——它让我意识到，卖工具入口这件事是可以做的。时隔一年多，DeepSeek 从一个我觉得"火不了"的模型，变成了一个定价变动能影响我业务的上游。

## Table of contents

## 当年那几十块，现在怎么看

2025 年初，DeepSeek 爆火。我在闲鱼做 API 搬运，赚了几十块钱。

说起来有点好笑——几十块，连顿饭都不够。但那是我第一次真正意识到：账号和工具入口，是可以卖的。不是卖课程，不是卖提示词合集，就是卖"进入某个工具的资格"。

在那之前我一直在卖提示词。9 块 9 一份，写半天，卖出去几份，收入低到我不想回忆。后来做了 AI 课程，写了几十万字，加起来卖了不到 30 块。我当时真的觉得：我是不是天生不适合做生意？

结果 DeepSeek 那几十块把我的认知调了个个儿。

同样的时间精力，搬运 API 赚的比写课程还多。这说明什么？说明信息差和工具入口的价值，远大于知识本身的价值——至少在这个阶段是这样。

所以我转型了。现在每天销售额大概 3000 块，毛利一千多。和那几十块比，数字差了好几个数量级。但逻辑是同一条：我就是那个"卖铲子的人"。

## DeepSeek 要涨价，我的第一反应

看到[即刻上的截图](https://m.okjike.com/originalPosts/6a73f45eba4a93d2ab36bfee)，官方说涨幅"较大"，具体数字还没出来。

我店里现在卖的是 Claude/Gemini/Codex 三合一账号，不是 DeepSeek API，所以直接影响不大。但我第一反应还是有点警觉——不是因为我在卖，而是因为我的用户在用。

我的很多客户买了 Claude 或者 Cursor，但日常还会混着用 DeepSeek API 跑一些批量任务。DeepSeek 涨价，他们的成本结构就变了，可能会转向问我：有没有更便宜的替代？

这种问题，我通常不好回答，因为我没有 DeepSeek 的货。但它确实可能带来询问量。

还有一件我更担心的事：DeepSeek 一涨，用户开始重新评估各模型的性价比，可能会重新比较 Claude API 和 DeepSeek API 的价格差距——如果差距缩小，Claude 的吸引力会上升一些，对我来说是好事。但如果用户因为整体 AI 成本上升开始精打细算，可能又会减少订阅型工具的购买，那就不好说了。

我自己逻辑没想清楚，就这样吧。

## 逆向 Kimi PPT 这件事让我有点在意

这条新闻我原本没打算聊，但越看越觉得有点意思。

有人花了几天把 Kimi 的 PPT 生成逻辑逆向出来，做成了开源 Skill，用 DeepSeek 也能跑出类似效果。作者还顺带提了一嘴：上次逆向网易云音乐收到了警告函，这次不知道会不会重演。

这句话戳到我了。

我之前在闲鱼搬运账号被封过号，扣了 20 分，封了 7 天。当时我的感受就是——我只是在做一个"信息中介"，并没有觉得自己在做什么违规的事，但规则就是规则，而且规则往往是有利于平台的。

逆向这件事也类似。技术上可行，逻辑上说得通，但法律边界模糊，最后的代价往往落在个人身上。

所以我现在对"有没有风险"这个问题格外敏感。一旦业务规模上去，每次平台调整规则、每次上游供应商跑路、每次某个关键工具断供，都直接影响收入。我的 Cursor 换号器就经历过几次突然不能用的情况，每次都要快速补货或者切方案，那几天的客服压力是真的大。

所以我没办法太激进，因为我是一个人在扛。

## 今天状态一般，但有一件事想说

最近我一直在想一个问题：我的生意本质上是在帮用户降低进入 AI 工具的门槛。

但这个门槛本身一直在降。

一年前，很多人不知道怎么用 Claude，不知道怎么科学上网，不知道 API 是什么。现在这些知识越来越普及，工具越来越傻瓜，连开户都有更多合规渠道在做。

所以我偶尔会想：信息差能撑多久？

我没有答案。但我观察到一件事：就算工具普及了，用户依然愿意为"不用折腾"付钱。我的订单里有一半以上是回购，不是因为用户不会自己弄，而是因为懒。或者说——时间比钱贵。

所以也许门槛不是关键，关键是"省事"这件事永远有市场。

只要我能把服务做得足够顺滑，信息差消失了，懒人红利还在。

我现在最需要解决的，其实是怎么把客服和售后从我身上剥离出来。这比找新项目更重要。
