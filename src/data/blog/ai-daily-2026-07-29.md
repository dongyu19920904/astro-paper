## 卖铲子的人看到新矿脉，第一反应是算账

Kimi K3 开源30分钟登顶 Hugging Face，[这条新闻](https://www.36kr.com/p/3915049412875392)我其实没有太多技术上的感慨——2.8T 参数、GDDR7 跑通、基准测试碾压之类的，看得懂皮毛，看不懂细节。

我真正在意的是：API 定价远低于 Claude。

这句话对我的意义和对开发者完全不一样。开发者想的是"能省多少 token 费"，我想的是——我店里卖的 Claude/Gemini/Codex 三合一，要不要调整定价策略？K3 这种价格如果能稳住，会不会抢走一部分本来打算买 Claude 中转的客户？

不一定。但这个问题今天在我脑子里转了挺久。

说实话，每次国产大模型爆出来，我都有点矛盾。一方面，用户涌进来，AI 工具热度上升，我生意通常会好一阵。另一方面，如果某个模型便宜到一定程度、又好用，用户就没必要买我的账号了——他们直接 API 平摊成本更划算。

DeepSeek 当年爆火的时候我就尝过一次这个滋味。那时候我在闲鱼卖 API 差价赚了几十块，然后发现卖的速度远跟不上用户"自己搞定"的速度。国产模型强，对我是双刃剑，不是纯好事。

## 翁荔离职那条，我看了两遍

[Thinking Machines 联合创始人翁荔离职](https://www.36kr.com/p/3914516361254281)，首款模型刚上线几天，她就走了，原因是健康。

这条新闻和我业务没什么直接关系，但我看了两遍。

她说过去7个月生病频率超过了人生任何阶段。我没有她那种级别的压力，但"被碎事切碎"这个感觉我是懂的。我每天的日常是：客服消息、补货、有人说买错了要退款、有个账号异常要排查、教程写了一半被一个售后问题打断、然后发现今天还没吃饭。

我的规模和她完全没法比，但那种"一直在动、一直没往前走"的感觉是相通的。

她是世界顶级的 AI 研究员，还是被节奏打垮了。所以那些说"你就是执行力不够、意志力不够"的——我现在不太信这套了。执行力有上限，身体有上限，注意力也有上限。

## Vibe Coding 那个案例，我有点想笑

[QA 主管用 AI 自建了 JIRA，四个月后悄悄装回 Linear](https://t.me/aigc1024/22612)。

这个我真的有点想笑，不是嘲笑他，是因为我也干过类似的事。

去年我用 AI 帮我搭了一套"自动回复+发货通知"的脚本，当时觉得太聪明了，以后客服省了。然后发现它偶尔会回错，偶尔不触发，偶尔把用户问题分类错——维护它花的时间，比我直接回复还多。

现在我看到任何"用 AI 自建工具替代 SaaS"的方案，第一个问题都是：出 bug 谁来修？凌晨两点炸了谁去查？

不是说不能做，是这个成本要算进去。第一版永远比买来的便宜，第三个月的维护成本就不一定了。

## MCP 那条我没太看懂，但感觉挺重要

[MCP 协议升级为无状态架构](https://x.com/dotey/status/2082235315675144569)这条，我承认我只看了个大概。

有状态变无状态、可以 serverless 部署、负载均衡之类的——我能理解字面意思，但具体意味着什么，老实说没完全想清楚。

我的直觉是：这对卖账号这个业务短期没影响，但如果 Agent 基础设施真的成熟了，以后用户要的可能不只是"一个能用的 Claude 账号"，而是"一套能跑起来的 Agent 系统"。那时候我卖的是什么？怎么卖？

这个问题我现在没答案，先记着。

我还没想出答案。但我觉得想清楚这个问题，比今天日报里任何一条新闻都重要。
