# 让 AI 找文档矛盾，先要它给出原句

一份长文档里，前面说周一交付，后面又写周三。假设你正准备核对这类材料，可以让 AI 先找一遍。我的要求会很具体，找到后要给出原句和位置，让人能回去看。

## 先拿到可以核对的回答

将要检查的材料交给工具，再试这段输入。这里的“找矛盾”只是一次初步筛查，不代替你读原文。

```text
请检查这份材料中有没有前后表述不一致的地方。
每一处请列出两段原句，并标出页码或段落位置。
说明它们为什么可能冲突。
没有找到时就写“没有找到”，不要补出原文没有的内容。
```

先看它有没有真的指向原句。若回答只有“这里可能存在风险”，没有位置，你还得从头找，这次辅助就没有解决眼前的问题。

## 找到了，还要看上下文

两处说法不同，也可能各自有条件。一处讲工作日，另一处讲节假日，就不能仅凭日期不同判定冲突。回到原文，读一下句子前后，再决定要不要改。

| 工具的回答     | 可以接着检查什么                     |
| -------------- | ------------------------------------ |
| 给出两段原句   | 原句是否存在，位置是否准确           |
| 解释了冲突原因 | 两段话是否在谈同一种情况             |
| 没有找到矛盾   | 仍保留人工核对，不能据此断定没有遗漏 |

我更愿意先做这种看得见结果的小任务。它有没有帮上忙，你能自己判断，不需要先懂一大堆模型名词。
