## 1. 先明确“第一名”是什么

Google、Bing 的自然结果、广告和 AI 答案引用是不同指标。关键词、地区、语言、设备、登录与日期也会改变结果。任何代码改动都不能保证第一名；没有 Search Console / Bing Webmaster Tools 的查询数据或实际 SERP，就不能声称当前第几名、搜索量多大或优化已涨排名。

本轮将两个目标分别处理：

| 查询 / 意图                                      | 机会与取舍                                                                                           | 主要承接页                       |
| ------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | -------------------------------- |
| AI 生命延续学、AI生命延续学                      | 更贴合作者长期方向，适合先建立清楚的本站定义；不能因查询较独特就断定有流量或竞争低                   | 现有 /topics/ai-longevity/       |
| AI 长生不老、AI长生不老                          | 意图更宽，可能混入科幻想象、数字永生、热点新闻和医学期待；需要诚实回答与概念区分，不以疗效承诺抢点击 | 同一专题内的问答段落             |
| AI 长寿研究、生物年龄与衰老时钟、AI 衰老开源项目 | 更具体且适合本站已有项目，能让读者完成找资料、比较证据、选择项目等任务                               | 专题、衰老时钟地图、相关历史文章 |
| yuyu AI 生命延续学                               | 作者实体与专题的准确对应；不冒充医学或科研机构                                                       | 关于页、专题与主页               |

“AI 生命延续学”在这里作为作者的内容方向解释，不宣称是已经获公认的独立学科。目标是建立一个值得进入、可核对且能持续积累的主题入口，不将整站改成关键词堆砌页。

## 2. 已确认的现状

1. 现有 Astro 静态输出、规范链接、Person / CollectionPage / BlogPosting / BreadcrumbList、站点地图、主题分页和 robots 已存在。不是没有 SEO 基础，不能为了审计凑项重做。
2. /topics/ai-longevity/ 目前是简短介绍、三个追踪问题、外链和按日期列表，缺少稳定的新手说明、证据比较和明确阅读路径。每天新日报不等于已经回答了入门查询。
3. 首页有侧栏专题链接，但首屏简介中的“AI 生命延续学”是普通文本；正文模板没有指向主题页的入口。已有主题识别函数可以复用，不必改旧文或再建一套分类。
4. GEO_PROFILE 的关键页面只列首页、作者、项目、博客和外部项目，未直接列本站专题。可补导航信息，但 llms.txt 并非 Google 排名技巧。
5. robots 的通配组已经允许抓取；没有发现 Claude-SearchBot 显式条目不代表被阻挡。本轮不为补名称而修改既有训练/搜索访问选择。能被普通请求访问也不等于真实爬虫已经抓取或索引。
6. 旧日报、知识库、收入、作者学历/经历都不是本轮 SEO 改写素材。不为专业感补“研究员”“医学专家”、临床验证、客户效果或测试经历。

## 4. 官方依据与适用边界

- [Google SEO 入门](https://developers.google.com/search/docs/fundamentals/seo-starter-guide)：不存在自动排名第一的秘诀；围绕读者、清晰组织、可发现链接，变化需要时间。
- [Google AI 搜索优化指南](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)：不需要特殊 AI 文件或专用 schema；llms.txt 不提升 Google 可见度，不为 AI 切碎内容或制造海量无价值页。
- [Google AI 功能与网站](https://developers.google.com/search/docs/appearance/ai-features)：先满足可索引、摘要资格及基本 SEO，结构化数据应符合可见内容；资格不是收录或引用保证。
- [Bing AI Performance](https://blogs.bing.com/webmaster/2026/2/Introducing-AI-Performance-in-Bing-Webmaster-Tools-Public-Preview/)：AI 引用应与传统自然结果分开测量，后续有站长后台数据时看真实查询和被引用页面。

claude-seo / seo-technical / seo-geo 与 claude-blog / blog-strategy 已用于核查和规划；本机 doctor 显示核心运行时 ready、未安装专用 Chromium。使用已有浏览器能力，不安装新 MCP、Skill、包或付费服务。工具内第三方百分比、固定字数、GEO 打分、更新频率不是本项目可证实的排名因素，不拿中文英文可读性分数当验收。

## 5. 内容与作者信任

首段直接解释本站用法，区分健康寿命、生物年龄、动物实验、人体研究与数字永生。用一张短表说明不同结果能支持什么、不能推到哪里；引用机构原文、论文和综述，保留文献类型，不把综述算作新的临床试验。

作者身份仍为 yuyu 的个人项目与内容记录者。新指南只介绍本站已有材料与公开来源，不编造“我试了”“我验证了”“研究证明人能永生”。没有诊断、用药、个人生物年龄测量、健康数据上传或寿命计算。

## 6. 推荐实施与不采用事项

先补强现有专题首页，并保持后续分页仍是列表；同一段长指南不能在每个分页重复。首页简介加自然文本链接，相关博客模板增加一个专题回链。GEO 页面目录补该规范 URL；标题/描述与可见内容一致，schema 保留原类型。

不新建多个近似“AI 永生/AI 长寿/AI 延寿”页面争同一意图，不加隐藏文本、强制引用指令、虚假 FAQ 富结果、伪造资质、购买链接、站群或伪造新鲜度。不批量重写历史文章，不增加每日模型调用，不改颜色控制器或自动发布链路。

IndexNow、GSC / Bing 后台提交与真实引用追踪有用但不等于排名；没有已核实的所有权配置时不猜 key、不改 DNS、不装新平台。先完成站内可控部分，并保留准确的未测量项。

## 7. 后续真实衡量

在 GSC / Bing Webmaster Tools 中，以规范专题页单独过滤，再比较四周窗口的展现、点击、查询与国家/设备；AI Performance / 可用的生成式搜索报告单独记录。不能只拿全站流量、51LA PV 或 site: 的结果数证明关键词排名。

第一次复查关注发现/索引与正确 canonical；随后再看前 20、前 10、前 3、前 1 的实际查询位置。目标档位是推进顺序，不是承诺几天必达。没有后台权限时保留“未知”，不要填 0 或用本地评分替代。
